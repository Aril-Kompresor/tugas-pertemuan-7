# Simulasi Repository Proyek RPL

## Tujuan Proyek
Melakukan simulasi manajemen konfigurasi dan kolaborasi repository proyek Rekayasa Perangkat Lunak menggunakan Git dan GitHub

## Tujuan Sistem
Sistem ini dibuat sebagai bentuk simulasi pengelolaan artefak perangkat lunak, pelacakan versi, serta alur kerja kelompok secara terstruktur

## Anggota Kelompok
- Aril
- Dani
- Zakir

## Struktur Proyek
- `requirements/` : Berisi dokumen kebutuhan sistem (SRS)
- `uml/`          : Berisi pemodelan diagram UML.
- `src/`          : Berisi kode sumber utama (*source code*)
- `test/`         : Berisi berkas dan skenario pengujian
